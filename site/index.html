Church and Basketball scheduling, week by week.

SignUpFlow gives coordinators, volunteers, players, and staff one local workflow for availability, qualified roster generation, publication, responses, cover, schedule changes, and the next planning horizon.

Read local setup Open playbooks

Tested roster operations

From the first invite to a published, calendar-synced schedule, with local API and browser evidence for the supported workflow.

⚙︎

Auto-scheduling solver

The greedy heuristic solver selects distinct qualified people, respects availability, and reports uncovered role slots.

◷

Availability & time-off

Volunteers set time-off and recurring (RRULE) unavailability; the solver respects every block.

↻

Self-serve & swaps

Volunteers claim open shifts and cover each other's swap requests without an admin in the loop.

⛁

Teams, roles & tenancy

Role-based access (admin / volunteer) and strict per-org isolation so every organization stays separate.

∑

Validated scheduling rules

Saved rules support assignment caps, minimum rest gaps, and a weighted cooldown preference. Unsupported predicates are rejected.

⧉

Calendar sync & analytics

Each volunteer gets an ICS subscription of published shifts, plus volunteer and event analytics.

{ }

API-first & CLI

Headless by design: a full REST API plus a YAML-in / JSON-out CLI for scripted, reproducible scheduling.

✉

Invitations & inbox

Token-based invites onboard people in one tap; an in-app inbox keeps assignees notified.
